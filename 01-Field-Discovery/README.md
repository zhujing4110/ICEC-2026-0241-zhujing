## 二、通用硬要求（来自考核大纲）

1. `raw_data/` 里必须有**原始数据表**（CSV 或 XLSX），不能只放结论
2. `photos/` 里必须有**本人现场同框认证照**——是"人和测量现场在同一个画面里"，不是纯截图
3. 报告要包含：采样设计 → 原始数据 → 图表 → 归因分析 → 改进方案（见 `report.md`）
4. 数据必须真实。评分明确写了「实事求是写出真实数据与尚未解决的缺陷，反而能获得更高评价」

## 四、课题 02 怎么测（模板已备）

文件：`raw_data/task02-phone-thermal.csv`（24 行 = 4 工况 × 6 时间点）

**用助手脚本，别手抄**：

```bash
python tools/task02_timer.py --mode 待机
python tools/task02_timer.py --mode 短视频
python tools/task02_timer.py --mode 导航/拍照
python tools/task02_timer.py --mode 高帧率游戏
```

每 5 分钟它会提醒你读电量与电池温度，**直接写进 CSV 对应那一行**，不用记行号也不用手算时间点。

**测量要点**：

- 每个工况开始前**静置 10 分钟**回到室温，否则上一轮余温会污染下一轮
- 全程不充电、亮度固定、连同一个 Wi-Fi
- 温度读**电池温度**（AccuBattery / DevCheck），不是电池健康度
- **同框照**：拍手机屏幕上的读数 + 桌面/环境一起入镜，证明是现场测的

**注意坑**：测「待机」时千万别边充边测，充电发热会把整条曲线拉平，数据直接作废。
