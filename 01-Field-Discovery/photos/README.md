# 现场照片放这里

## 必须是"本人现场同框照"

考核要求的是**证明你本人在测量现场**的照片，不是手机截图、不是网上找的图。

合格的画面：测量设备（手机/分贝仪）的屏幕读数 + 周边环境特征 + 你的手或身影。

## 命名规范

```
task02-01.jpg   课题02 第1张（测待机工况）
task02-02.jpg
task06-图书馆-早.jpg
task06-食堂-午.jpg
```

## 每个课题至少 3 张

- 课题02：至少覆盖 2 种不同工况的开机画面 + 1 张温度读数特写
- 课题06：5 个点位各 1 张（可只提交 3–5 张，但要有不同点位的环境差异）

## 注意

照片里不要出现他人正脸（校园里拍到路人要避开或打码），不要出现身份证、学号等信息。
