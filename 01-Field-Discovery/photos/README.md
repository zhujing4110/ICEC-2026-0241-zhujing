# 现场照片放这里

## 必须是"本人现场同框照"

考核要求的是**证明你本人在测量现场**的照片，不是手机截图、不是网上找的图。

合格的画面：测量现场的客观特征（队伍、窗口招牌、设备读数）+ 你的手或身影，进同一个画面。

## 命名规范

```
task04-01.jpg   课题04 第1张（完整队列 + 窗口招牌，能看到窗口开了几个）
task04-02.jpg   课题04 第2张（高峰时刻的队伍长度，带手机计时画面更好）
task04-03.jpg   课题04 第3张（窗口打饭/扫码的特写，用于说明单次服务耗时）
task10-01.jpg   课题10（终端运行脚本的画面 + 桌面/环境）
```

## 每个课题至少 3 张

- **课题 04**：至少 3 张，必须在**测量过程中**拍，不能测完再补。
  最好覆盖三个状态：高峰前的短队、峰值时的长队、开始回落。
  画面里要能看出**这是哪个窗口**（招牌/编号）和**大概几个人在等**，否则无法与 CSV 里的排队人数互相印证。
- **课题 10**：屏幕上是 `tests/task10_benchmark.py` 运行结果的表格 + 终端的执行输出，
  一张即可；有第二张显示 CSV 被写入的效果更好。

## 为什么必须现场拍

官方要求：原始数据与照片要能接受**面试现场溯源**。
课题 04 的照片是证明"这 15 组数不是编的"的唯一凭据——照片里的天色、队伍长度、窗口数量，
要和 CSV 里同一时点的排队人数对得上。事后补拍是最容易被拆穿的一种造假，不要做。

## 注意

- 照片里**不要出现他人正脸**：拍队伍时从人群背后或侧后方取景，实在避不开就打码
- 不要出现身份证、学号、饭卡余额等个人信息
- 课题 10 的照片若拍到了终端，注意不要把个人目录路径、密钥之类的内容框进去
