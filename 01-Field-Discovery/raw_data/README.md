# raw_data 说明：哪些是真数据，哪些是算出来的，哪些是空表

评审打开这个目录，第一眼需要分清三件事：哪张表是实测、哪张是模型算出来的、哪张只是模板。这里先讲清楚，避免逐张打开猜。

| 文件 | 归属 | 性质 |
|---|---|---|
| `task04-model-params.csv` | 课题 04 | **参数表，不是数据**。λ、μ、RTT 全为教学示例值，逐行标注来源；改这里即可把模型标定到真实场景 |
| `task04-analytic-vs-sim.csv` | 课题 04 | **模型输出**：解析解 vs 离散事件仿真（食堂 60,000 人长运行 + 批均值 CI；电梯 20 组固定种子） |
| `task04-canteen-scenarios.csv` | 课题 04 | **模型输出**：食堂五方案对比（ρ、Wq、Lq、降幅、成本） |
| `task04-elevator-scenarios.csv` | 课题 04 | **模型输出**：电梯五方案对比（RTT、运力、ρ、5 min 净积压、30 min 末队列） |
| `task04-sensitivity-lambda.csv` | 课题 04 | **模型输出**：λ 从 20 扫到 50，找 ρ 的「膝部」 |
| `task04-sensitivity-windows.csv` | 课题 04 | **模型输出**：窗口数 10→18，看边际收益递减 |
| `task10-batch-audit.csv` | 课题 10 | **有实测**。脚本侧耗时实测（重复 3 次取中位）；人工侧为估算模型，不设实测列，倍数标「按估算」 |
| `task10-benchmark-result.json` | 课题 10 | **实测**：两次运行的原始计时，由 `tools/task10_benchmark.py` 生成 |
| `task10-repo-inventory.csv` | 课题 10 | **实测**：任务 C 产物（仓库文件清单），同上脚本生成 |
| `task02-phone-thermal.csv` | 课题 02（附录） | **空表**：24 行结构，数值列全空，本次未采集 |
| `task02-phase-start.csv` | 课题 02（附录） | **只有表头**：同上 |

四点补充：

1. **课题 04 六张表全部可由一条命令重算**：`python tools/task04_queue_model.py`。仿真用固定随机种子（20261124），结果逐位可复现——这意味着表里的每个数都不是"写上去的"，而是"跑出来的"。
2. **课题 04 的参数不是实测值**。这一点在参数表每一行都写了「教学示例值」，在 `report.md` 课题 04 第 6 节列为第一条局限。它能证明"给定这些参数，模型算出什么"，不能证明任何一所学校的真实客流。
3. **空表不等于占位**。课题 02 交付的是采样设计、记录脚本、核算脚本与表结构，数据本身没有采——该课题已撤回申报，报告里降为附录，没有填任何推测值。
4. **估算与实测分列存放**。课题 10 里凡估算值，列名带「估算」；凡实测值，列名带「实测」，不混用。人工侧不另设空的「实测」列——空列容易被读成「忘填」，写明「估算」是明确的方法选择。
