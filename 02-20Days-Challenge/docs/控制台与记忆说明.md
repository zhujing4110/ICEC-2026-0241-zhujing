# 控制台与长期记忆

两个新东西：一个浏览器页面管所有事，一个让它记住你。

---

# 一、控制台

## 打开方式

启动 bot 后，浏览器访问：

```
http://127.0.0.1:8765/
```

启动日志里也会打印这行地址。只监听本机，外网访问不到。

## 页面上有什么

| 区域 | 能做什么 |
|---|---|
| **运行状态** | 账号、已运行多久、今日主动几条、近 1 小时发了几条、记忆条数、知识库规模 |
| **暂停 / 恢复** | 右上角按钮。暂停后不回复、不主动，但进程和微信窗口保持不动 |
| **主动消息** | 三个按钮（早安 / 晚安 / 接上一句），手动让她现在说一句。**会真的发出去**，点了会二次确认 |
| **人设** | 直接编辑 `persona.md`，保存后**下一条消息就生效**，不用重启 |
| **长期记忆** | 看她记住了什么，按时间倒序 |
| **日志** | 最近 120 行，3 秒自动刷新 |

暂停是内存里的开关，**重启 bot 后自动恢复运行**（不会记住暂停状态）。

## 端口被占怎么办

改 `config.json`：

```json
"webui": { "enabled": true, "host": "127.0.0.1", "port": 8765 }
```

换个端口，或者 `enabled: false` 彻底不开。端口起不来时机器人会继续跑，只是没有控制台。

# 二、长期记忆

## 它和知识库不是一回事

| | 谁写的 | 内容 | 位置 |
|---|---|---|---|
| **知识库** | 你手写 | 她是谁、怎么回答常见问题 | `knowledge/*.md` |
| **长期记忆** | 它自己攒的 | 对方在做什么、有什么困扰 | `memory/*.json` |

## 什么时候记

每轮回复**发出去之后**，后台起一个线程问模型："这轮对话里有什么关于对方的、值得长期记住的事？" 记下来。

放在后台是为了不拖慢回复 —— 你收到消息的时间不受影响。

## 记什么、不记什么

提取 prompt 只要三类：**在做什么事**（学业/工作/项目）、**困扰和目标**、**喜好和称呼**。

明确排除：寒暄、情绪波动、一次性的时间安排、她自己说过的话。

实测：

```
「我下周要交网页设计大作业，还差个首页，配色一直不满意，老师说要简约点」
  → 在做网页设计大作业 / 作业要求简约风格 / 配色选择有困扰

「我是学人工智能的，现在在自学剪映，想做短视频」
  → 学人工智能 / 自学剪映 / 想做短视频

「你好啊，今天天气不错」
  → （空，不记）
```

## 怎么用起来

每次生成回复前，按当前这句话的相关性挑最多 6 条塞进提示词：

```
## 你记得他的事
这些是你以前跟他聊天时攒下的印象，需要时自然带出来，
别列清单、别说「我记得你说过」。

- 学人工智能
- 自学剪映
- 想做短视频
```

所以你说"剪映又卡住了"，她知道你在做短视频，不用你再解释一遍。

## 存储与上限

一人一个文件：`memory/wxid_xxxx.json`

```json
{
 "user": "wxid_MAIN_MASKED",
 "updated": 1795418026.1,
 "items": [
  { "text": "学人工智能", "ts": 1795418026.1 },
  { "text": "自学剪映", "ts": 1795418026.1 }
 ]
}
```

- 默认每人最多 **40 条**（`memory.max_items`），超了丢最旧的
- 按文本去重，同一句不会记两遍
- **可以直接手改**：删掉不想要的、加几条你想让她记住的，她下次就知道

## 配置

```json
"memory": {
  "enabled": true,
  "max_items": 40,      // 每人上限
  "inject_limit": 6     // 每次最多注入几条
}
```

`inject_limit` 调大会让她"记得更多"，但也会挤占上下文，建议不超过 8。

# 三、生效

代码改了两个文件（`bridge.py` 集成）+ 两个新文件（`memory.py`、`webui.py`），**必须重启**：

1. 关掉 bot 窗口
2. 双击 `start-bot.bat`
3. 浏览器打开 `http://127.0.0.1:8765/`

重启后 1 分钟内她会主动发一条（距上次聊天已超 45 分钟），紧接着你回一句，就能看到：
- 控制台日志里出现「记住 N 条新事实」
- 记忆区多出几条
- 下一句回复里她自然地用上这些信息

# 四、排查

| 现象 | 原因 |
|---|---|
| 页面打不开 | 端口 8765 被占（改 `webui.port`），或 bot 没启动 |
| 页面能开但状态全空 | 还没绑定微信窗口，看日志有没有绑定失败 |
| 记忆一直是 0 | 对话太短（少于 4 字不提取），或者都是寒暄 |
| 记忆乱记 | 直接改 `memory/*.json` 删掉，比调 prompt 快 |
| 人设保存后没变 | 人设是热加载，但只有**下一条消息**才用新版本 |
