# 她收到了什么：图片、表情包、语音、文件

## 以前是什么样

`handle_chat` 里有一行过滤：

```python
and m.get("type") == "文本"
```

你在微信里发一张图、一个表情包、一条语音，只要不是文字，就被这行扔掉。更糟的是**水位照常推进**——这条消息被标记成"读过了"，之后也不会补回来。所以你发表情包给她，她不是不回，是根本不知道有这回事。

## 现在她能收到什么

非文本消息会被翻译成一行她能读的字，跟你打的字一起进缓冲区，等你发完再一起回应：

| 你发的 | 她看到的 |
|---|---|
| 表情包（认得） | `[他发来一个表情包：无语]` |
| 表情包（认不出） | `[他发来一个表情包]` |
| 图片 | `[他发来一张图片]` |
| 语音 | `[他发来一条语音，4 秒]` |
| 文件 | `[他发来一个文件：作品集.pdf]` |
| 链接 / 公众号文章 | `[他发来一个链接：标题]` |
| 卡片 | `[他发来一张卡片：标题]` |
| 位置 / 视频 / 红包 | `[他发来一个位置]` 这类 |
| 系统消息、通话记录 | 不理（不是人发的话） |

顺序也保留：先发图再跟一句话，就是"图 → 话"这个顺序给她，不会打乱。

**只发表情包、一个字不打，她也一定会回**——沉默判定只对纯文字应答生效，发了图就等于人在说话，装没看见很失礼。

## 能看懂到什么程度（说清楚，别期待过高）

| 能做 | 做不到 |
|---|---|
| 知道你发了图/表情/语音/文件 | 看不到画面里画的是什么 |
| 认得和自己库里同一张表情包的情绪 | 认不出没见过的图 |
| 看到文件名、链接标题、语音时长 | 听不到语音内容、打不开文件 |
| 你教过的表情，以后同款都认得 | 自己看图猜情绪 |

原因很直接：环境里只有 `deepseek-flash` 和 `deepseek-v4-pro`，**都是纯文本模型**，没有视觉能力。所以她的反应是"知道有这回事，但不知道里面是什么"，会自然地问你一句，而不是瞎猜。

实测她收到东西后是这样回的：

```
[他发来一个表情包]        → 这啥表情 ／ 没认出来
[他发来一个表情包：无语]   → 又咋了 ／ 谁惹你了
[他发来一张图片]          → 图没显出来，你直接说是什么吧
[他发来一条语音，4 秒]     → 语音我这边听不到 ／ 你直接打字说？
[他发来一个文件：作品集.pdf] → 嗯，看到了 ／ 这作品集是打算发给谁看的吗
```

不会出现"这猫好可爱""这张我收藏了"这种编造——提示词里明确禁止，而且禁止她承诺"我打开看看"这种做不到的事。

## 表情包是怎么认出来的

微信的表情消息本身带 `md5`，这个 md5 就是**原图的 md5**（可验证：从 CDN 下载的 GIF 算出来一模一样）。所以：

1. **md5 精确匹配**：你自己库里那张图的 md5 和她看到的一致 → 直接读出标签
2. **平均哈希兜底**：图被转过码、md5 变了，但 8×8 平均哈希只差 0-8 位 → 也能认出来
3. **你教的**：在控制台给某个 md5 写一句「狗头，反讽」→ 以后同款都认得

原图从微信 CDN 直接拉（明文 GIF，不用解密），存到 `inbox/emojis/<md5>.png`（只留第一帧、缩到 320px）。同一张只下一次，之后读缓存。

**图片**走的是另一条路：本机 `.dat` 解密（`download_image`，只读磁盘、不驱动界面），存到 `inbox/images/`。本机没有那份文件时只留描述，不会去点开你的微信界面。

## 控制台的「他发来的」

`http://127.0.0.1:8765/` 里新增一张卡片，在「表情包」下面：

- 左边缩略图，右边是那行描述、时间、以及**认不认得**
- 图下面是输入框：写一句「狗头，意思是反讽」，点「记住」，以后同款她就知道
- 输入框清空再点「记住」= 取消认识
- 语音、文件这类没有图的，只显示那一行文字

这一步是整个功能里最有效的：**你教一次，她永久认得**。库里只有 9 张表情包，但她可以认识你手上所有常用的梗。

## 参数

```json
"inbox": {
  "enabled": true,
  "dir": "inbox",
  "max_items": 60
}
```

`max_items` 是控制台保留最近多少条记录（缩略图文件不会自动删，需要的话手动清 `inbox/`）。

改了要重启——这属于启动时初始化的模块。

## 已知限制

- **看不到画面**。这是模型能力问题，不是代码问题。要真正识图得换多模态模型。
- **动图只取第一帧**。表情包存成 PNG 是为了省空间，动画丢了。
- **图片落地依赖本机文件**。你发的图如果微信只存了缩略图，她拿到的也是缩略图。
- **`inbox/` 会慢慢变大**。一张表情约 30-80KB，图片不压缩，攒多了自己清。
