# 自学与主见说明

让她"自己上网学点东西"，不是真的自主意识 —— 大模型每次开口都是一次性推理，没有持续的思考。
这里做的是三件能落地的事：**自己决定查什么、自己查、查完沉淀成她自己的笔记**。

## 一、她怎么决定学什么

两个来源：

| 来源 | 触发 | 例子 |
|---|---|---|
| 聊天里不懂的 | 每轮回复发出后，后台问一句"刚才有没有你没把握的具体名词" | 你说"在做剪映"，她记下"剪映" |
| 自己好奇的 | 队列空了，按 `learn.interests` 想一个具体问题 | "深圳地铁导视 AI 改过吗" |

只挑**具体名词**：工具、产品、地方、事件、专业说法。情绪、天气、寒暄不会进队列 —— 实测"今天好累啊"返回空。

## 二、她怎么学

1. 从队列取一条（聊天里带出来的优先）
2. 先把问题压成 2 组短关键词 —— Bing 对长中文/中英混排查询会切错词，短词才搜得准
3. 逐组搜 4 条，**过一道相关性闸门**：结果和问题对不上就换下一组，全都不行就放弃
4. 读第一条网页正文，让模型写 2-4 句笔记，**资料里没有的就写"没查到"，不硬编**
5. 写进 `knowledge/learned/{话题}.md`，带查证日期、搜索词和来源链接
6. 知识库自动重新索引（5 秒内），下次聊到就能用上

笔记长这样：

```markdown
# BM25 算法

> 我自己上网查的（2026-11-23），来源 zhuanlan.zhihu.com。记得不一定准，说的时候留点余地。

BM25（Best Matching 25）是经典信息检索算法，1994 年由 Stephen 提出，基于 Okapi TF-IDF 改进。
关键点是对 TF-IDF 做词频饱和与文档长度归一化，并有概率检索理论基础。

## 来源
- https://zhuanlan.zhihu.com/p/670322092
```

## 三、什么时候学（四道刹车）

```json
"learn": {
  "enabled": true,
  "max_per_day": 5,          // 每天最多 5 条
  "min_gap_minutes": 20,     // 两次之间至少隔 20 分钟
  "start": "09:00",          // 深夜不学
  "end": "23:00",
  "idle_minutes": 10,        // 你 10 分钟内说过话就不学，先把注意力留给你
  "allow_invent": true,      // 队列空了允不允许自己想题
  "queue_max": 40,
  "learned_dir": "learned",
  "interests": "视觉设计、AI 工具、深圳本地生活"
}
```

日志里能看到每次判定，只在原因变化时记一行，不会刷屏：

```
暂不自学：刚聊过 2 分钟，先把注意力留给他
暂不自学：距上次自学还有 17 分钟冷却
暂不自学：今天已经学了 5 条，到上限了
开始自学：剪映（她说在做短视频）
自学完成（今日第 1 条）：剪映 → 剪映.md（131 字）
自学放弃：某话题（资料里没有可用解释）
```

## 四、学到的怎么用

**只在相关对话里自然用出来，不主动汇报。**

她的笔记进了知识库，你说"剪映又卡住了"，检索会把那篇笔记塞进提示词，她就"正好知道"。但不会说"我今天学了剪映"——那样像在答题，不像聊天。

笔记里那句"记得不一定准，说的时候留点余地"是给模型看的，让它转述时别把网页内容当铁律。

## 五、控制台

`http://127.0.0.1:8765/` 新增"好奇心与自学"卡片：

- 左栏 **待学**：队列里的问题，标注来源（聊天里 / 自己想的 / 手动），可单条删除
- 右栏 **已学**：已经写好的笔记，可删除（删了知识库里对应内容一起失效）
- 输入框填话题 + 「现在学一个」= 手动让她立刻查一个，跳过所有刹车
- 留空点「现在学一个」= 让她从队列里挑第一条

## 六、主见（另一半）

光有知识不叫"独立思考"，还得有态度。`persona.md` 加了一段：

```
## 有自己的判断
- 不同意就直说，不用"确实不错，不过…"这种先捧后转
- 不确定就说"我不太确定"，不要为了接话硬给答案
- 有自己的偏好，会直接说哪个更好、哪种做法更靠谱
- 但别为了显得有主见而抬杠，对方对的地方就认
```

配了一条示范：对方「白色和米色哪个好」→ 你「白色吧|米色容易显旧」。

## 七、成本与风险

- 每条回复多两次后台 API 调用（记忆提炼 + "有没有不懂的"判断，各约 600 tokens），DeepSeek 下可忽略
- 每次自学：1 次关键词改写 + 1~2 次搜索 + 1 次读网页 + 1 次写笔记（约 1500 tokens）
- **风险一：网上资料本身可能错。** 所以每篇笔记都带来源链接，控制台可一键删；笔记里那句"记得不一定准，说的时候留点余地"是给模型看的，让它转述时留后路
- **风险二：搜索引擎会抽风。** 实测 5 个真实问题命中 3 个（60%）。Bing 对"剪映专业版导出步骤"这类中英/长句查询会把词切错，返回"即 百度百科"这种页面。处理方式：先换关键词重试，仍不行就**放弃，不写笔记**（宁可少学，不能学错）；没查成的题会在队列里保留，下次再试一次，两次都失败才真正放弃
- 一件事她不重复学：队列里已学的、`learned/` 里已有同名笔记的，都不会再入队
