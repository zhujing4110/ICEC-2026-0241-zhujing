# 迭代 07 · 她收不到表情包："没回"的真相是"没看见"

- 日期：2026-11-24
- 类型：功能缺失修复（消息类型覆盖不全）
- 影响文件：新增 `src/inbox.py`；`src/bridge.py`（`handle_chat` / `pending` / `_deliver`）；`src/persona.md`；`src/webui.py`；`src/config.json`

## 现象

使用者的提问："能不能让她看到我发的表情包？"

此前她只回文字。发一张图过去，她会像没收到一样——连"你发了个啥"都不会问。

## 定位

`handle_chat` 的过滤条件里有一行：

```python
if m.get("type") != "文本":
    continue
```

非文本消息在**这一行被丢弃**。更糟的是，水位（`last_seq`）照常推进——程序认为这条消息"处理过了"。所以这不是"没回"，是**永久性地没看见**。这类 bug 最隐蔽：日志里连一行记录都不会留下。

## 需要先搞清楚三件事

摸黑写代码会白折腾。先把微信 4.x 的消息形态测清楚：

| 问题 | 实测结论 |
|---|---|
| 有哪些消息类型 | 文本 / 图片 / 动画表情 / 语音 / 视频 / 文件·链接·卡片 / 位置 / 系统消息 / 音视频通话 |
| 表情包能不能拿到原图 | **能**。XML 里的 `<emoji md5=... cdnurl=...>`，**md5 就是原图 md5**（下载后校验完全一致） |
| 原图从哪来 | `cdnurl` 直接 GET 返回**明文 GIF**，不用解密、不用 aeskey |
| 本地缓存能用吗 | 不能。`cache/YYYY-MM/Emoticon/` 下的文件是加密的，试了 ascii / hex 两种 aeskey 都解不开 |
| 图片怎么拿 | `MediaDownloader.download_image()` 只读本机 .dat，不驱动界面 |
| 卡片消息的标题在哪 | 是**子元素** `<title>`，不是属性；`type` 也是子元素（6 = 文件） |

「原图 md5 和我自己库里的 md5 一致」这一条是关键：她可以拿收到的表情包和自己的库做**精确匹配**，不需要视觉能力。

## 实现

### 1. 新增 `inbox.py`

`Inbox.accept(msg, user)` 把任意一条非文本消息转成一行可读文本：

```
[他发来一个表情包：无语]
[他发来一张图片]
[他发来一条语音：12 秒]
[他发来一个文件：作品集.pptx]
[他发来一个链接：https://...]
```

表情包识别三级优先：`known.json`（人工教过的）> 自己库的 md5 > 平均哈希汉明距离 ≤ 8。命中的图落地到 `inbox/emojis/<md5>.png`（取 GIF 首帧、缩到 320px），图片落地到 `inbox/images/`。

### 2. `bridge.py`

- `handle_chat` 收全部类型，`pending` 增加 `parts`（有序：文字原样 + 事件带方括号）
- `_answer(user, texts, parts)`：`texts` 给模型看上下文，`parts` 给模型看"他到底发了什么"
- `_should_stay_silent` 在无文字时直接返回 False——**只发一个表情包也必须应一声**，否则等于没收到
- 记忆与自学只吃纯文字（`plain`），避免把方括号当事实记进去
- prompt 常驻一段「## 方括号」，有媒体时再追加「## 他发的是图，不是字」

### 3. 控制台

新增「他发来的」卡片：缩略图列表 + 类型 + 时间 + 识别结果，可对着一张图写一句"这是什么"，写完后同类表情自动认得（`known.json`）。

## 能力边界的诚实话

**她背后的模型是纯文本模型，没有视觉能力。** 所以准确表述是"知道有这回事，看不到内容"。这必须写进 prompt，否则模型会顺着"你是 AI"的语境开始编图里的内容。

实测回复：

| 输入 | 回复 |
|---|---|
| `[表情包]`（没认出来） | 这啥表情 / 没认出来 |
| `[表情包：无语]` | 又咋了 / 谁惹你了 |
| `[图片]` | 图没显出来，你直接说是什么吧 |
| `[语音]` | 语音我这边听不到 |

prompt 里明确禁止：夸图、猜图、说"收藏了/听到了"、承诺"我打开看看"、解释自己是文字模型。

## 验证

`tests/inbox-test.py` 11 项：真实表情包落地 + md5 匹配、教过就认得、缓存不重下、各种消息类型转文本、系统消息不理、纯表情不静默、图文混合顺序、`handle_chat` 不再丢非文本。

`tests/inbox-webui-test.py` 8 项：列表、缩略图、三种越权路径 404、写注释、同款自动认得、留空取消、缺参 400、页面含新卡片。

## 遗留

- 视频只记"收到一个视频"，抽帧需要 ffmpeg，未做
- 语音不转文字（要接 ASR），只能告诉对方"听不到"
- 表情识别依赖 md5/哈希，**改了尺寸或换了帧的同一张表情认不出来**
