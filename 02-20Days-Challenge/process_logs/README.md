这些是程序运行时由 `logging` 自动写入的真实日志，不是事后补写的。日志中每条记录都带毫秒级时间戳，可以直接用来还原当时发生了什么。

## 脱敏规则（为什么日志里是"主号A/小号B"）

原始日志包含两个真实微信号的 wxid 和昵称。这两个号仍在日常使用，直接公开等于把账号 ID 暴露在公网。所以做了机械替换，**只改标识，不改任何时间、内容、耗时、报错**：

| 原始 | 替换为 |
|---|---|
| 真实 wxid（主号） | `wxid_MAIN_MASKED` |
| 真实 wxid（小号/机器人） | `wxid_BOT_MASKED` |
| 主号昵称 | `主号A` |
| 小号昵称 | `小号B` |
| API Key | 从不写入日志；`config.example.json` 中为占位符 |

替换后用正则复查过，无残留的 `wxid_` 真实值和 `sk-` 密钥串。

## 局限

日志只覆盖 11-21 一天约 1 小时 46 分钟，不是连续 7 天。程序本身没有做日志轮转和长期归档，这是后续要补的（见主 README 第七节"已知缺陷"）。
