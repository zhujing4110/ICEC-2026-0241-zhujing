# 怎么改人设和知识库

## 一、改人设：`persona.md`

打开 `persona.md` 直接改，**保存后下一条消息就自动生效，不用重启**（程序每次回复前会检查文件有没有改动）。

里面几块比较关键：

| 段落 | 作用 | 改它的时机 |
|---|---|---|
| 基本信息 | 名字、年龄、身份 | 想换个身份/改名 |
| 性格 | 说话的气质 | 觉得太客气 / 太冷淡 |
| 说话方式 | 长度、语气、口头禅 | 回复太长、太像 AI |
| 会做的事 / 不会做的事 | **红线** | 想让它敢聊某些话题，或堵住某些话题 |
| 口头禅 | 具体用词 | 想更像某个人 |

不会做的事那一块最重要，别删。里面有"不承诺时间价格""不透露账号密码""不聊政治"这些护栏。

## 二、加知识：`knowledge/` 目录

往里丢 `.md` 或 `.txt` 就行，**存盘 5 秒内自动生效，不用重启**。

### 写法决定命中率

检索是关键词匹配，所以**用别人会怎么问来写小标题**，比写成说明书命中率高得多。

推荐这样：

```markdown
## 能帮忙做设计吗 / 怎么收费

可以聊需求，具体报价和排期要号主本人定。
价格按工作量和紧急程度报，不做免费改稿。
```

不推荐这样：

```markdown
## 服务说明

本服务提供平面设计相关咨询，价格面议。
```

第二种写法，用户问"多少钱""怎么收费"基本匹配不上。

### 几个实用规则

1. **一个小标题说一件事**。标题会一起参与匹配，所以标题要包含关键词。
2. **同一件事的多种说法写进标题**，用 `/` 隔开，例如 `## 在哪个城市 / 住哪 / 在哪里`。
3. **一段别太长**，300 字以内最合适。
4. **没写的就说不知道**，比硬编安全。空着比写错好。

## 三、验证命中：`kb-test.py`

改完别急着发微信，先本地试：

```bat
.venv\Scripts\python.exe kb-test.py "你能帮我做海报吗"
.venv\Scripts\python.exe kb-test.py "怎么收费" --raw
```

- 加了 `--raw` 会列出所有候选和打分，用来判断是"没写"还是"门槛太高"
- 分数低于 `config.json` 里的 `knowledge.min_score`（默认 1.2）就不会被采用
- 命中太多不相关的，把 `min_score` 调高；该答的答不上，调低到 0.8 试试

## 四、相关配置项

`config.json` → `knowledge`：

```json
{
  "enabled": true,
  "dir": "knowledge",
  "top_k": 3,          // 每次注入几段资料
  "min_score": 1.2,    // 命中门槛，越高越保守
  "max_chars": 900     // 注入资料的字数上限
}
```

`enabled: false` 就只用人设聊，不查知识库。

## 五、回复太长怎么调

回复长度由四层共同决定，从强到弱：

| 位置 | 参数 | 当前值 | 作用 |
|---|---|---|---|
| `config.json` | `behavior.max_reply_chars` | 32 | **硬上限**，超了就在逗号处截断。想更短改小，想宽松改大 |
| `config.json` | `behavior.max_sentences` | 2 | 最多保留几句，多出来的句子整句丢掉 |
| `config.json` | `deepseek.max_tokens` | 150 | 模型单次输出上限。太小会出现半句话 |
| `persona.md` | 「长度示范」小节 | — | 模型照着示例的长度写，这一条最影响语气 |

改前两个要重启；改人设不用。

如果还是觉得长，先把 `max_reply_chars` 降到 24 试试——微信里真人一句通常就这么长。

## 六、能不能上网查资料

能，但**按需触发**：闲聊不联网，只有问到实时信息才查。

模型判断要查时会先输出一行 `SEARCH: 关键词`，程序拿这个词去 Bing 搜，再把结果塞回去让它重新回答。代价是慢一点：平常 1 秒，联网 3-4 秒。

| 问题 | 联网 | 实测 |
|---|---|---|
| 深圳今天天气 | ✅ 走 wttr.in | 深圳今天多云，20 度 |
| DeepSeek 最新模型 | ✅ 走 Bing | V4.1 Flash，11 月发的 |
| iPhone 17 多少钱 | ⚠️ 常查不到 | 会说"没查到"，不瞎编 |
| 你好 / 闲聊 | ❌ 不查 | 1 秒正常回复 |

配置在 `config.json` 的 `web_search`：

- `enabled`：总开关，关掉完全不联网
- `default_city`：问天气但没说城市时用这个（默认深圳；留空会按出口 IP 猜，实测经常猜错）
- `top` / `read_top`：取几条搜索结果、抓第一条网页正文
- `max_per_hour`：每小时最多查几次

改这些要重启程序。「什么时候该联网」的说明是程序拼进提示词的，不在 `persona.md` 里，想调整得改 `bridge.py` 的 `build_system_prompt`。

**边界**：能拿到的是"网页上写着的文字"。天气走专用接口所以准；电商实时价格、要登录才能看的内容基本查不到——这时候它被要求直说查不到，而不是编一个。

## 七、常见问题

**Q：回复里出现"根据资料""知识库里说"这种话？**
人设的"不会做的事"里加一条：不要提资料、知识库、记录这类词。

**Q：问什么都答不上来？**
先跑 `kb-test.py`。没命中就是知识库没写，命中了但没答好就是人设在压。

**Q：改了不生效？**
知识库 5 秒自动重载；人设保存后下一条消息自动生效；**只有 `config.json` 要重启程序**（模型、频率、白名单这些是启动时读一次的）。
